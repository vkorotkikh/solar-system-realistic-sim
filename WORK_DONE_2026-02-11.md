## Development Work Completed

### 1. Earth spin/orientation fixes

- Reworked spin-axis transform so body obliquity is applied relative to the ecliptic normal (+z), avoiding pole alignment errors in the orbital plane.
- Updated rotation progression to be deterministic from simulation Julian date (instead of frame-time accumulation drift).
- Added explicit Earth rotation phase offset metadata for map alignment.

Key files:

- `src/main.js`
- `src/data/planets.js`

### 2. Oort cloud updates

- Replaced the single-shell approximation with a two-component structure:
  - denser inner Hills-like cloud
  - broader outer shell
- Kept Oort visibility synced with UI toggle in render flow.

Key file:

- `src/main.js`

### 3. Milky Way realism pass (procedural)

- Audited prior procedural model and identified realism gaps:
  - over-pronounced brightness at wide zoom
  - insufficient separation between subtle/default and enhanced rendering
- Implemented structured enhanced procedural model with:
  - thin/thick disk + bulge weighting
  - longitude density shaping
  - dust-lane attenuation approximation
  - color shifts by region

Key file:

- `src/main.js`

### 4. Milky Way mode toggles

- Added UI mode controls and behavior split:
  - Standard Milky Way (subtle)
  - Enhanced Milky Way (high contrast procedural)
  - Survey Milky Way (2MASS texture-based)
- Added deterministic mode precedence:
  - `Survey` overrides `Enhanced`
  - otherwise falls back to `Standard`

Key files:

- `index.html`
- `src/main.js`
- `README.md`

### 5. Survey Milky Way implementation

- Added survey texture asset:
  - `src/assets/textures/milky_way_2mass_equirect_2048.jpg`
- Built a survey sky-sphere (inside-facing) with galactic-to-equatorial orientation matrix.
- Centered sky backdrop layers on camera each frame to maintain far-field background behavior.

Key file:

- `src/main.js`
