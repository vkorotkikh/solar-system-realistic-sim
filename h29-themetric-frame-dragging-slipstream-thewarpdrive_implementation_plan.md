# H29: The Metric-Frame-Dragging Slipstream (The Warp Wave)

A solitary, massive, non-linear metric frame-dragging surge from Sgr A*'s catastrophic barycenter failure. Unlike oscillating GW stretch-and-squeeze ripples, this is an Alcubierre-like transient warp bubble—a "smoke ring" of warped spacetime blowing outward at *c*. Objects inside don't accelerate; the *metric itself* translates them. Observers would measure apparent velocities drastically exceeding *c* because the atoms are motionless locally within a surfing bubble of warped reality.

**Mathematical basis:** ADM formalism shift-vector $\beta^i$ transient spike. The metric reduces to the Alcubierre form:
$$ds^2 = -dt^2 + (dx - v_s f(r_s) dt)^2 + dy^2 + dz^2$$
naturally generated by the angular momentum collapse of Sgr A* and radially dissipating over parsecs.

### Physics Core

#### [MODIFY] [smbhPropagation.js](file:///home/nomad/Documents/solar-system-realistic-sim/src/frontend/features/solar/smbhPropagation.js)

Add three new exported functions in a new `// METRIC-FRAME-DRAGGING SLIPSTREAM (H29)` section:

1. **`warpBubbleProfile(xi)`** — The solitary wave shape function. Takes normalized coordinate $\xi = (r - c \cdot t) / \sigma$ where $\sigma$ is the bubble thickness. Returns $f(\xi) \in [0,1]$ using a smooth sech² soliton profile: $f(\xi) = \text{sech}^2(\xi)$. This is the radial cross-section of the "smoke ring."

2. **`metricFrameDragShift(distanceCm, timeSec, energyErg, smbhMassG)`** — Computes the ADM shift-vector magnitude $|\beta^i|$ at a given radial distance and time. The shift propagates outward at $c$ as a solitary pulse:
   - Bubble center: $r_0 = c \cdot t$
   - Bubble thickness: $\sigma \propto (E / M_{\rm BH} c^2)^{1/3} \cdot r_0^{1/2}$ (broadens with distance)
   - Peak amplitude: $\beta_{\rm peak} \propto (G \cdot \Delta J) / (c^3 \cdot r_0)$ — decays as $1/r$
   - Returns the local shift-vector value using `warpBubbleProfile()`

3. **`coordinateStretchFactor(distanceCm, timeSec, energyErg, smbhMassG)`** — The observable: how much local spatial distances are momentarily stretched. Returns a multiplicative factor $(1 + \epsilon)$ where $\epsilon = \partial \beta^i / \partial r \cdot \Delta t$. During passage, this briefly makes the Earth-Sun distance appear to change without any force.

### Spacetime Warp Visualization

#### [NEW] [warpSlipstreamVisuals.js](file:///home/nomad/Documents/solar-system-realistic-sim/src/frontend/features/solar/warpSlipstreamVisuals.js)

A dedicated Three.js shader-mesh visualization for the warp slipstream, separate from the existing GW grid (which shows oscillatory GWs). This renders the solitary warp "smoke ring":

**Vertex Shader:**
- A large plane/sphere-section geometry oriented along the Sgr A* propagation direction
- Vertices behind the warp front are *pulled outward* (expansion region)
- Vertices at the warp front get asymmetric compression-ahead / expansion-behind displacement
- The displacement profile follows the sech² soliton shape

**Fragment Shader:**
- Renders a distortion grid (like [gravitationalWaves.js](file:///home/nomad/Documents/solar-system-realistic-sim/src/frontend/features/solar/gravitationalWaves.js) but with fundamentally different character)
- Intense violet/white glow at the wavefront (frame-dragging energy density)
- Behind the wave: fading afterglow showing the "slipstream" corridor
- Space ahead of the wave: undistorted

**Integration points:**
- `createWarpSlipstreamVisualization(size)` factory function
- [update(dtSec)](file:///home/nomad/Documents/solar-system-realistic-sim/src/frontend/features/solar/gravitationalWaves.js#149-156) called from sunController update loop
- `setWarpState({ position, amplitude, thickness })` called from AGN engine
- [toggle(on)](file:///home/nomad/Documents/solar-system-realistic-sim/src/frontend/features/solar/gravitationalWaves.js#157-165) visibility control

- When `stretchFactor > 1.0`: multiply each body's `relativePosition` magnitude by the stretch factor along the warp propagation direction
- This is a *coordinate transformation*, not a force — orbital elements remain unchanged, only the spatial representation stretches temporarily
- Bodies maintain their Kepler elements; only the display position stretches
- After the bubble passes, positions snap back smoothly (exponential relaxation)
