\section{Scope and constraints}
This analysis is tailored to the current code context: preserve causality while implementing a high-fidelity apparent-superluminal layer. We separate the model into three layers:
\begin{enumerate}
\item geometry and observation,
\item plasma/MHD transport,
\item multi-messenger channels (GW, CR, neutrino, EM flare).
\end{enumerate}

\section{Physics of apparent superluminal motion}
Superluminal features in compact jets are interpreted as finite-light-travel-time effects rather than information faster than light. For bulk motion $\beta=v/c$ at viewing angle $\theta$,
\[
\beta_{\mathrm{app}} = \frac{\beta \sin\theta}{1-\beta\cos\theta}.
\]
For large $\beta$ and small $\theta$, $\beta_{\mathrm{app}}>1$.

\section{Why a re-architecture is needed}
A realistic architecture requires distinct channels:
\begin{enumerate}
\item source descriptor,\
\item per-messenger transport,\
\item rendering layer.
\end{enumerate}
A fixed-speed, toy-only front can be kept as a visual mode, while the physical mode uses causal transport.

\section{Causal hierarchy}
\subsection{Strict causality layer}
No transport channel carries information above $c$. GW and EM radiative fronts remain near-luminal.

\subsection{Apparent pattern layer}
Pattern speed (knots, shock fronts, hotspots) can produce apparent speeds above $c$ while preserving local causal transport.

\subsection{Coupled multi-messenger layer}
Shared launch metadata should drive delays:
\begin{itemize}
\item launch epoch,
\item direction vector,
\item opening angle,
\item channel energy budget,
\item decay law.
\end{itemize}

\section{Source ranking}
\begin{enumerate}
\item Sagittarius A*: closest SMBH at $\sim26{,}000\,\mathrm{ly}$; intermittent activity. Useful for high-cadence local disturbance tests.
\item Centaurus A: nearest radio-loud AGN at $\sim3.8\,\mathrm{Mpc}$; strong jet and VLBI constraints; good active analog.
\item M87: jet/knots with resolved superluminal features; useful for structured-jet scenarios.
\item Maffei 1: nearby elliptical but weak AGN behavior; useful as a low-activity control.
\end{enumerate}

\section{Multi-messenger ordering}
\begin{enumerate}
\item GW channel: causal and prompt; constrained by GW170817--GRB timing.
\item EM jet channel: delayed by jet opacity and afterglow geometry.
\item CR/neutrino channel: delayed diffusion and scattering, often with broader spread.
\end{enumerate}

\section{Implementation recommendations}
\begin{enumerate}
\item Add event schema with per-channel delay/dispersion rules.
\item Keep fast visual speeds as an optional visual-only mode.
\item Add explicit simulation modes: \texttt{visual\_mode} and \texttt{physical\_mode}.
\item Add source presets for Sgr A*, Cen A, M87, Maffei 1.
\item Log $\beta_{\mathrm{app}}$, arrival lag, and confidence tags per channel.
\end{enumerate}

\section{Confidence and risks}
Pattern speed may not equal plasma speed; CR/neutrino transport uncertainties are large; beaming and orientation dominate apparent speed.
