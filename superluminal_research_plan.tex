\title{Research and Implementation Plan: Superluminal Fronts in AGN/SMBH Context}
\date{}
\maketitle

\section{Objective}
Build a causally safe, physically interpretable, and multi-messenger-aware simulation of apparent superluminal behavior.

\section{Phase 0 --- Source and parameter baselines}
\begin{enumerate}
\item define source presets with fixed provenance.
\item store in config format with confidence labels.
\item include Sgr A*, Cen A, M87, Maffei 1.
\end{enumerate}

\section{Phase 1 --- Causal kinematics core}
\begin{enumerate}
\item implement apparent-geometry transform.
\item implement observer-time mapping and delay.
\item separate visual mode and physical mode output channels.
\end{enumerate}

\section{Phase 2 --- Multi-channel scheduler}
\begin{enumerate}
\item replace fixed toy speed with typed event object.
\item add delayed kernels for GW, EM, CR, neutrino proxies.
\item include channel-specific decay and dilution.
\end{enumerate}

\section{Phase 3 --- Transport and morphology}
\begin{enumerate}
\item add 1--2 zone jet structure (spine/sheath).
\item add Doppler beaming and light-curve modulation.
\item add optional shock regions and CR transport toy module.
\end{enumerate}

\section{Phase 4 --- Validation set}
\begin{enumerate}
\item define benchmark signatures: apparent-speed curve, flare timing, delayed channel onset, orientation sensitivity.
\item compare to anchor cases: GW170817-like delay ladder, MOJAVE-like distributions, Cen A scales, causality checks.
\end{enumerate}

\section{Phase 5 --- Advanced speculative features}
\begin{enumerate}
\item add `advanced\_mode` toggle.
\item add optional coupling terms (Gertsenshtein-like, GW memory proxy).
\item keep defaults disabled and documented as speculative.
\end{enumerate}

\section{Query pack}
\begin{enumerate}
\item Rees 1966 apparent relativistic expansion Nature DOI
\item MOJAVE XVII 2019 dataset
\item Cen A TANAMI inner parsec jet
\item GW170817 superluminal jet Nature 2018
\item Bell 1978 diffusive shock acceleration
\item Gertsenshtein effect coupling
\end{enumerate}

\section{Recommended rollout}
Phase 0+1 first for immediate usability; Phase 2 if multi-messenger visuals are required; Phase 3 for stronger science behavior.
