# Research navigation

The canonical historical SMBH research reference is
[the consolidated 09:00–10:42 master](SMBH_Shockwave_Research_MASTER_2026-02-23T0900-104200.md).
This designation provides one navigation target; it does not certify every
scientific claim or imply that all hypotheses are implemented.

[09:00 master](SMBH_Shockwave_Research_MASTER_2026-02-23T0900.md) remain unchanged
historical variants. Their differences and original timestamps are preserved.
The [astrophysics index](../ADVANCED_ASTROPHYSICS_INDEX.md) inventories the wider
research collection. Current runtime scope is in [README](../README.md) and
