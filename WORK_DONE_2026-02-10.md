## Detailed Change Notes

1. Gravity vectors

- Added UI toggle: `toggle-gravity-vectors`.
- Added vector rendering group with `ArrowHelper` instances per major massive body.
- Added per-frame net-gravity computation (sum of acceleration vectors from other massive bodies).
- Wired visibility/update in render loop and display toggle handling.

2. Realism locators and label readability

- Added UI toggle: `toggle-locators`.
- Reworked label sprite styling to gold/orange text and explicit downward arrow indicator.
- Added halo locator sprite for sub-pixel body visibility.
- Added distance-aware, screen-stable sprite scaling so labels do not become unusably small in realistic mode.

3. Planet textures and visual realism

- Added local 2K textures for:
  - Mercury, Venus, Mars, Jupiter, Saturn, Uranus, Neptune.
- Added Earth cloud layer and Venus atmosphere shell for improved depth cues.
- Kept Earth 4K day + 2K normal mapping.

4. Axial tilt and spin

- Added `axialTiltDeg` + `rotationPeriodHours` fields to Sun/planets/Pluto data in `src/data/planets.js`.
- Introduced per-body spin groups in scene graph.
- Applied axial tilt as spin-group orientation.
- Added per-frame spin updates using rotation period metadata.

5. Star background upgrade

- Replaced random isotropic stars with:
  - star-catalog-driven point layers (color and magnitude bins),
  - synthetic Milky Way band in galactic coordinates.
- Added reduced star catalog data file: `src/data/stars_catalog.json`.

6. Asteroid belt upgrades

- Replaced static belt placement with element-driven orbital propagation.
- Implemented adaptive detail LOD count based on zoom/proximity.
- Added local perturbation refinement (massless test particles under Sun/Jupiter/Saturn) for close-up belt views.

7. Moon frame normalization

- Added frame normalization logic for moon orbits so mixed source frames are converted to a unified ecliptic approximation.
- Stored source frame metadata (`orbitFrameSource`) in catalog entries.

8. Documentation

- Updated `README.md` to reflect new features, limitations, and data sources.
