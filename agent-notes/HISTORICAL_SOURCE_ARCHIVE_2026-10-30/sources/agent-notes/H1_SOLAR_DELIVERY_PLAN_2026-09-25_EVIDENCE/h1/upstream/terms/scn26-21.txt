Alternative RTSW Products
 
 
Replacement products are available now at the following 
 
endpoints:
 
 
https://services.swpc.noaa.gov/json/rtsw/rtsw_ephemerides_1h.jso
n
  
https://services.swpc.noaa.gov/json/rtsw/rtsw_mag_1m.json
   
https://services.swpc.noaa.gov/json/rtsw/rtsw_wind_1m.json
  
 
These updated RTSW products include both \223source\224 and \223active\224 
metadata 
fields:
 
 
source 
\227 
identifies the satellite from which the data originated
 
 
active 
\227 
a boolean indicating whether the satellite was 
considered active 
  
         
by SWPC forecasters at the time
 
 
The deprecated products included data only from whichever satellite was 
deemed active at the time, without exposing this 
metadata.
 
 
The original values, excluding the \223time_tag\224 value were stored 
as quoted 
strings, while the replacement values are numeric floats without quotes.
 
 
The replacement files for the deprecated magnetometer and solar 
wind 
products contain four of the old timeframes (1
-
day, 2
-
hour, 
5-
minute and 
6-
hour). To support the updated cadence, 3
-
day and 
7-
day users must 
retrieve and retain the 1
-
day file.
 
 
The replacement file for the ephemerides product will be updated 
to 
include the data into the next month that the deprecated 
product 
provides.
 
 
Data Element Mapping
 
 
RTSW Plasma (Wind)
 
The \223time_tag\224 field is the same in the replacement, for 
 
\223density\224 users will need to use \223proton_density\224, \223speed\224 will 
 
map to \223proton_speed\224, and \223temperature\224 maps to 
 
\223proton_temperature\224. 
 
 
RTSW Magnetometer (Mag) 
 
The \223time_tag\224, "bx_gsm", "by_gsm", "bz_gsm", "bt" fields are 
 
the same in the replacement, "lon_gsm" users will need to use 
 
"phi_gsm", "lat_gsm" will map to "theta_bsm".
